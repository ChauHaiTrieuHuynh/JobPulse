# Job Finder # - # JobPulse #
## Overview 
  - The project is built to customize how I tracking and find a software engineer first full time job.
  - LinkedIn and Indeed already had the notification job but the result is mixing and data is not consistent and did not help me to reduce the time
  - So this project built also to stay up with the technology and challenge myself to host and release the product from end to end
  - Project is built with C#/.NET
    
## Problem
  - New software engineering positions can receive significant attention shortly after being posted.
  - Manually checking multiple job sources throughout the day is repetitive and can result in discovering relevant opportunities too late.
    
## Goals
  - Periodically discover newly posted software engineering jobs.
  - Filter opportunities using configurable titles, locations, and keywords.
  - Track previously discovered jobs to prevent duplicate notifications.
  - Notify the user when a new matching opportunity is discovered.
